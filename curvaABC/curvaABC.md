# 📊 Projeto: Análise de Curva ABC com Power BI + Python

Este projeto apresenta uma análise completa de Curva ABC aplicada a um dataset comercial, integrando Python para validação dos cálculos e Power BI para visualização final.
O objetivo é demonstrar habilidades práticas em tratamento de dados, modelagem, DAX e construção de dashboards empresariais.

## 🚀 Objetivos do Projeto

* Realizar a limpeza e preparação dos dados.

* Calcular a receita total por produto.

* Classificar os itens em Categorias A, B e C utilizando a técnica de Curva ABC.

* Validar todos os números usando Python (Pandas).

* Criar um dashboard profissional no Power BI.

* Entregar uma visão clara para tomada de decisão.

## 🛠️ Ferramentas Utilizadas

* Python (Pandas, NumPy) – para tratamento e validação dos cálculos

* Power BI – para ETL leve, modelagem e construção dos dashboards

* DAX – para métricas e KPIs

* Jupyter Notebook

## 🧹 Etapas Realizadas

* Conversão correta de decimal (ponto → vírgula).

* Remoção de registros com Quantity <= 0 ou UnitPrice <= 0.

* Ajuste de tipos numéricos.

* Remoção de duplicidades entre InvoiceNo + StockCode.

## 📈 Resultados Principais

Após alinhar Python e Power BI, os valores finais ficaram:

* Contribuição da Categoria A: 79,98%

* Quantidade de Produtos A: 803

* Contribuição da Categoria C: 5,01%

(Comprovado e validado.)

## 📌 Insights do Projeto

* A maior parte da receita está concentrada em poucos produtos (Categoria A).

* Há uma longa cauda de itens C com contribuição muito baixa.

* O gestor pode priorizar estoque, compras e atenção comercial nos itens A.

* Itens C podem ser analisados para possível descontinuação.
